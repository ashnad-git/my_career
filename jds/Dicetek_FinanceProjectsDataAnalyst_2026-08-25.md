## Full Job Description (verbatim)

The Finance & Projects Data Analyst is responsible for the end-to-end data migration workstream covering financial and project data. This role owns the extraction, analysis, mapping, cleansing, and reconciliation of data from Sage Evolution (Finance) and Deltek Vantagepoint (Project Management) into Oracle Fusion Cloud Financials and Oracle Project Portfolio Management (PPM).

Essential Requirements:
- Minimum 3 years' experience in ERP data migration or data analyst roles
- Hands-on experience with Oracle Fusion Cloud Financials or Oracle PPM (FBDI, ADFdi, HCM Data Loader)
- Proficiency in Microsoft Excel (advanced: Power Query, pivot tables, VLOOKUP, data validation)
- SQL querying for data extraction and validation
- Experience with Sage Evolution or Deltek Vantagepoint preferred

Note: Highly specialized ERP migration role — Ashnad's Odoo ERP migration experience is adjacent but Oracle Fusion Cloud hands-on is required.
