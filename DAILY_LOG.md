## WHAT CLAUDE DOES WITH THIS

At the start of every session, Claude reads the most recent entry and:
- ✅ If full completion → acknowledge + move on to today's session
- ⚠️ If partial → ask what got in the way, adjust today's session if needed
- ❌ If skipped → address directly before starting learning. Not judgementally — but honestly. Skipping has a cost and Claude will name it.
- 🔁 If skipped 3 days in a row → stop learning session, diagnose the real issue
