## How to use each file

1. Open the file in Excel
2. Go to the **Exercises** sheet
3. Write your formula in column D — no hints allowed after Level 1
4. When done, go to **Data → Format → Sheet → Unhide → Answer Key** to check
5. Report your answers to Claude before checking — honest self-assessment first
